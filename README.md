# Bioastronautics Quiz Prep: 6 Mini Quizzes

A study site focused on the 4 questions on the upcoming quiz.

| Mini quiz | Covers | Quiz question |
|---|---|---|
| 1. CV Calcs: Resistance & Cardiac Output | R = ΔP/Q, CO = HR × SV, Fick equation | Q1 |
| 2. CV Calcs: Stroke Volume, Ejection Fraction & PV Loops | SV, EF, PV loop phases, contractility, preload/afterload, P_ms | Q1 |
| 3. The Cross-Bridge Cycle | 4 steps, Ca²⁺/troponin/tropomyosin, ATP's two roles | Q2 |
| 4. Muscle Spindles (True/False + explain) | intrafusal/extrafusal, α/γ, Ia/II, bag/chain, α-γ coactivation, stretch reflex | Q3 |
| 5. Countermeasures | CV, muscle, bone, SANS, artificial gravity | Q4 |
| 6. Mock Quiz | all four topics mixed | all |

The calculations reuse the worked examples from the Cardiovascular System I & II slides: 90 → 5 mmHg with 5 L/min ≈ 83 cc/s giving 1 PRU, the Fick equation, the P_ms tilt example, and ΔP = TPR × CO. A formula sheet on the home page lists every formula with its slide example.

After every answer you get an explanation, and on multiple-choice questions you also see why each wrong option is wrong. Your best and last score for each quiz is saved in your browser.

## Files

- `index.html`: the website
- `questions.js`: the quizzes, formula sheet and questions. Edit this file to add or change questions.

## Run it

- **On GitHub Pages:** go to Settings → Pages → Deploy from a branch → `main` / `(root)`.
- **Locally:** double-click `index.html`.
